## Introduction

Implement a cloth simulator using position-based dynamics (PBD) and NVIDIA
Warp. The starter creates a triangulated cloth, fixes its top midpoint,
builds edge constraints, and runs Warp kernels on the CPU or a supported GPU.
The seven numbered TODOs are in `cloth_pbd.py`.

The [Tutorial 6 slides](./COMP7508_ANI_T6_PBD.pdf) cover the PBD concepts
used in this assignment.

The solver uses parallel Jacobi projection: edge corrections are computed
separately and then gathered per vertex.

## Environment

Use Python 3.10 or newer. A GPU is optional; `--device cpu` runs the same Warp
kernels. The pinned Warp 1.19.0 PyPI wheel needs an R580-series or newer
NVIDIA driver for CUDA. For older drivers, follow the official
[CUDA 12 wheel instructions](https://nvidia.github.io/warp/v1.19/user_guide/installation.html)
and use `--device cuda:0`.

```bash
cd assignment_3
python -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python env_test.py
```

`env_test.py` checks installation, kernel compilation, and mesh setup only.
It cannot validate cloth motion until the TODOs are completed.

On Windows, activate with `.venv\Scripts\activate` instead.
For CUDA 12 drivers on Linux x86-64, replace the default Warp package after
installing the requirements, then run the same check on the GPU:

```bash
python -m pip install --force-reinstall --no-deps \
  'https://github.com/NVIDIA/warp/releases/download/v1.19.0/warp_lang-1.19.0+cu12-py3-none-manylinux_2_28_x86_64.whl'
python env_test.py --device cuda:0
```

## Task 1 - PBD cloth simulator (90%)

Complete all **7 numbered TODOs** in `cloth_pbd.py`. Mesh setup, kernel launch
order, output, and rendering are provided.

1. **TODO 1-2 (20%)**: apply gravity and damping, then predict positions.
2. **TODO 3-4 (40%)**: evaluate each edge's distance error and compute the
   inverse-mass-weighted endpoint corrections.
3. **TODO 5 (15%)**: gather and relax the corrections for each vertex.
4. **TODO 6-7 (15%)**: recover velocity and commit corrected positions.

Preserve the single fixed vertex, avoid division by zero if predicted edge
endpoints coincide, and keep edge corrections separate until the gather step.

After completing the TODOs, run the main program to save a submission video:

```bash
python cloth_pbd.py --device cpu
```

This command runs 400 steps at `dt=0.01` and saves `cloth.mp4` in the current
directory. The default rate follows simulation time (50 fps), giving an
approximately four-second video. `imageio-ffmpeg` in `requirements.txt`
provides the video encoder. Use `--video path/to/result.mp4` to choose another
destination, `--video cloth.gif` for GIF, `--no-video` for OBJ frames only, or
`--fps 15` for slow motion. OBJ frames appear in `frames/`. The starter
launches and writes the initial cloth, but it will not move until you complete
the TODOs. You can preview existing frames with:

```bash
python preview.py --input frames
```

The command line provides `--nx`, `--ny`, `--dt`, `--iterations`, `--alpha`,
and `--damping` for experiments. You may supply a custom cloth with
`--mesh path/to/cloth.obj`; polygon faces are triangulated, and the middle
vertex on its highest y row is pinned. Try `--device cuda:0`
after the CPU version works.
The default uses 64 Jacobi iterations; lower values run faster but allow
more visible stretching.
